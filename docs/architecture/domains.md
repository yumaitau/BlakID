# Domains

- `blakid.au` product
- `console.blakid.au` control plane and organisation administration
- `status.blakid.au` status
- `docs.blakid.au` documentation
- `api.blakid.au` public API
- `{organisation}.id.blakid.au` or customer-owned `id.customer.org.au` for the identity environment

Customer-owned domains are encouraged.
